# Actividad N° 11: Feria Artesanal de Ñuble
## Objetivo
Construir un sitio web interactivo en Vue 3 que integre formularios, condicionales, vistas y componentes modales.
## Pasos realizados
- Interfaz del catálogo con buscador y filtros (v-model, computed).
- Mostrar/ocultar secciones (v-show).
- Tarjetas de producto reutilizables (ProductoCard.vue).
- Ventana modal interactiva (ProductoModal.vue) mediante eventos (emit).
