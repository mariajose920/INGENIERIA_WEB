# Actividad N° 10: Backend con NestJS (compatibilidad Express)
## Objetivo
Migrar el backend a NestJS manteniendo endpoints, sumando validación, TypeORM y Swagger.
## Pasos realizados
- Módulo emprendedores con CRUD completo.
- Uso de class-validator y class-transformer (DTOs).
- Configuración de base de datos con TypeORM.
- Documentación de API mediante Swagger.
