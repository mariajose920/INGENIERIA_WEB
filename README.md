# Actividad N° 3: Manejo de eventos y comunicación inversa con emisión (emit)
## Objetivo
Comprender y aplicar el sistema de emisión de eventos personalizados en Vue.js, para enviar información desde un componente hijo hacia el componente padre.
## Pasos realizados
- Creación de HijoBoton.vue.
- Emisión de evento $emit('saludo') al hacer clic.
- Captura del evento en Padre.vue para mostrar un mensaje.
