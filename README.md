# Actividad N° 2: Creación de componentes y comunicación con props
## Objetivo
Comprender y aplicar el sistema de componentes de Vue.js, utilizando props para enviar datos desde el componente padre al hijo y mostrar información dinámica en pantalla.
## Pasos realizados
- Estructura de carpetas y componentes (src/components/Padre.vue, src/components/Hijo.vue).
- Comunicación unidireccional usando props (mensaje).
