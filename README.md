# Actividad N° 5: Condicionales (v-if, v-else, v-show) y listas dinámicas (v-for)
## Objetivo
Aplicar estructuras condicionales y renderizado dinámico de listas utilizando las directivas -if, -else, -show y -for.
## Pasos realizados
- Construcción de una lista de tareas (to-do list) dinámica.
- Uso de -show para ocultar/mostrar.
- Uso de -for para renderizar tareas.
- Mensajes alternativos con -if.
