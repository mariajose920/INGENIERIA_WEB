# Actividad N° 1: Instalación de entorno de desarrollo Vue.js con Vite
## Objetivo
Lograr configurar de forma autónoma y exitosa el entorno de desarrollo moderno para aplicaciones Vue.js, utilizando Vite, Node.js y GitHub.
## Pasos realizados
- Instalación de Node.js.
- Creación de proyecto con Vite (Vue + JavaScript).
- Instalación de dependencias (
pm install).
- Ejecución del servidor de desarrollo (
pm run dev).
- Repositorio inicializado en GitHub.
