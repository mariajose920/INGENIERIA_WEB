# Actividad N° 8: Adaptación a Empresa de Servicios
## Objetivo
Reutilizar y ampliar el proyecto anterior para una empresa de servicios, integrando catálogos, filtros y navegación.
## Pasos realizados
- Adaptación del caso a un sistema de Servicios.
- Implementación de navegación SPA (Inicio, Nosotros, Servicios, Contacto).
- Catálogo dinámico de servicios con uso intensivo de -for, -model y computed.
- Filtros interactivos de servicios y formulario de contacto.
