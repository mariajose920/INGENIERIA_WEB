# Actividad N° 12: SPA con Vue Router y favoritos persistentes
## Objetivo
Transformar el proyecto en una Single Page Application (SPA), usando rutas, componentes reutilizables y persistencia.
## Pasos realizados
- Configuración de Vue Router (Inicio, Catálogo, Favoritos, Contacto, Detalle).
- Rutas dinámicas (/productos/:id).
- Persistencia de favoritos en el navegador mediante localStorage.
- Página de error 404.
