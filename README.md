# Actividad N° 9: Primer Backend con Express.js
## Objetivo
Construir el primer backend del proyecto web mediante Node.js y Express.js, estructurando rutas GET y filtrado.
## Pasos realizados
- Creación de servidor server.js con Express.
- Datos de servicios servidos mediante API REST.
- Búsqueda por ID (eq.params) y filtrado por categoría (eq.query).
- Habilitación de middleware express.json().
